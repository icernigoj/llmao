# Contributing to llmao

Thanks for helping make a fake LLM slightly more convincing. Contributions of all sizes are welcome: new jokes, bug fixes, docs, and support for more SDK features.

## Setup

You need Node 22+ and pnpm 9.

```bash
git clone https://github.com/<you>/llmao.git
cd llmao
pnpm install
pnpm check   # typecheck, tests, build and a smoke test: the same as CI
```

## The fastest way to contribute: a new skill

A skill is a regex that pretends to be intelligence. Skills live in [`src/skills.ts`](src/skills.ts). Each one gets the prompt and returns an answer, a few reasoning steps, and optionally a confidently wrong alternative (used when the model hallucinates):

```ts
const dice: Skill = {
  name: 'dice',
  run({ text, language, rng }) {
    if (!/\broll (?:a |the )?(?:die|dice|d6)\b|\btir[aá] (?:un|el) dado\b/i.test(text)) return null; // not for me

    const roll = rng.int(1, 6); // use rng, never Math.random, so seeds stay reproducible
    return {
      answer: say(language, { en: `You rolled a ${roll}.`, es: `Salió ${roll}.` }),
      steps: [say(language, { en: 'Rolling a die in my latent space…', es: 'Tirando un dado en mi espacio latente…' })],
      wrong: () => ({ answer: say(language, { en: 'You rolled a 7.', es: 'Salió 7.' }) }),
    };
  },
};
```

This `dice` skill is real, so you can read it next to the others. Then:

1. Add it to the `SKILLS` array. Order matters: the first skill that matches wins, and `confidentFallback` must stay last.
2. Answer in English and Spanish (`language` is `'en'` or `'es'`).
3. Add a test in [`test/core.test.ts`](test/core.test.ts), using the `sober` instance (instant, no hallucinations, temperature 0) so the answer is exact:

   ```ts
   it('rolls dice', async () => {
     expect((await sober.ask('roll a die')).text).toMatch(/^You rolled a [1-6]\.$/);
   });
   ```

Good skills are funny *and* correct when they're supposed to be. The joke is the confidence, not a wrong answer by default.

## A new model

Models are personalities, defined in [`src/models.ts`](src/models.ts). The easy kind reuses an existing persona with different defaults:

```ts
'lmao-sloth': {
  persona: 'overthinker',
  description: 'Thinks slower than any model in history. Still answers 2 + 2.',
  defaults: { speed: 'dramatic', temperature: 0.5 },
},
```

A new persona (a new way of talking, like `corporate` or `safe`) also needs a branch in `think()` in [`src/brain.ts`](src/brain.ts). Add a test in the `models` block of `test/core.test.ts`.

## Other contributions

- **SDK compatibility**: the adapters are `src/openai.ts`, `src/anthropic.ts` and `src/ai-sdk.ts`. `test/compat.types.ts` checks them against the official SDK types; if you add a response field, keep it assignable to the official type.
- **Docs**: the guides are Markdown files in [`site/content/`](site/content). Preview the site with `pnpm build && SITE_URL=http://localhost:4173 pnpm site`, then serve `site-dist/`.
- **Bugs**: a failing test is the best bug report.

## Conventions

- No em dashes in docs, comments, UI text or commit messages. Use a colon, comma, period or parentheses. (Answers generated by llmao may use them.)
- Zero runtime dependencies.
- Tests must pass for every random roll: use `seed`, `hallucinationRate: 0` and `speed: 'instant'`, and inclusive bounds.
- Keep the humor in answers and models, and keep the docs clear about what is a joke and what is real.

## Pull requests

Keep them focused: one skill, one fix or one feature per PR. CI runs the same `pnpm check` on Node 18 to 24. By contributing, you agree to license your work under the [MIT license](LICENSE).
